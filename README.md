# Device tree for Xiaomi Pad 5 (codenamed _nabu_)


## Device specifications

| Device                  | Xiaomi Pad 5                                                                                 |
| ----------------------- | :--------------------------------------------------------------------------------------------|
| SoC     		          | Qualcomm Snapdragon 860                                                                      |
| CPU           		  | Octa-core (1x2.96 GHz Kryo 485 Gold & 3x2.42 GHz Kryo 485 Gold & 4x1.78 GHz Kryo 485 Silver) |
| GPU     	        	  | Adreno 640                                                                                   |
| Memory                  | 6GB RAM                                                                                      |
| Shipped Android Version | 11 (MIUI 12)                                                                                 |
| Storage                 | 128/256GB                                                                                    |
| Battery 		          | Li-Po 8720 mAh, non-removable                                                                |
| Display       		  | IPS LCD, 120Hz, HDR10, 11.0 inches, 1600 x 2560 pixels, 16:10 ratio (~274 ppi density)       |
